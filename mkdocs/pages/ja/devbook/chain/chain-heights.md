# チェーンの高さと不可逆高さを照会する

<get:/chain/height> エンドポイントは、現在のチェーンの高さを返します。

**不可逆高さ** は、これ以上ロールバックできない最も高いブロックです。
NEM では、現在のチェーンの高さから [書き換え制限](default:書き換え制限) を引いて計算します。

このチュートリアルでは、ループでチェーンの高さをポーリングし、不可逆高さを計算して、チェーンの高さが最後に変化してからどれくらい時間が経過したかを追跡する方法を説明します。

## 前提条件 {: #prerequisites }

このチュートリアルでは、SDK を必要とせずに [NEM REST API](../reference/rest/nem.md) を使用します。
HTTP リクエストを送信する方法だけが必要です。

### チェーンの高さを取得する {: #fetching-chain-height }

反復のたびに、コードは <get:/chain/height> エンドポイントへ `GET` リクエストを送信します。

新しいブロックが生成されるたびに、チェーンの高さは増加します（およそ 60 秒ごとです）。

### 不可逆高さを計算する {: #calculating-the-irreversible-height }

{{ tutorial.code_snippet_tagged('step-2') }}

[書き換え制限](default:書き換え制限) は、NEM でロールバックによって取り消せるブロック数の上限で、**360 ブロック**（およそ 6 時間）に設定されています。

現在のチェーンの高さからリライトリミットを引くと、**不可逆高さ** が得られます。

不可逆高さ以下のブロックは、これ以上ロールバックできません。

ロールバックとリライトリミットの詳細については、テキストブックの [コンセンサス](../../textbook/consensus.md#conflict-resolution) セクションを参照してください。

### 高さの変化を追跡する {: #tracking-height-changes }

{{ tutorial.code_snippet_tagged('step-3') }}

チェーンの高さが最後に変化してからの経過時間を表示するため、コードは前回の高さと、最後に更新された時刻を保存します。

新しいブロックが到着して高さが変化するたびに、タイムスタンプを更新します。
その後、経過時間を現在のチェーンの高さとともに表示します。

### ポーリングループ {: #polling-loop }

{{ tutorial.code_snippet_tagged('step-4') }}

各反復では、次の情報を示すステータス行を 1 行表示します。

* 現在のチェーンの高さと、最後に変化してからの経過秒数。
* 不可逆高さ。

その後、ノードをもう一度照会する前に 1 秒間スリープします。

出力の要点は次のとおりです。

* **新しいブロックの前**（2～4 行目）: プログラムがポーリングを続ける間、チェーンの高さは変わりません。
* **新しいブロックが到着**（5 行目）: チェーンの高さが `659,471` から `659,472` に進みます。
    不可逆高さも進みます。

!!! note "チェーンの高さと不可逆高さの違い"

    不可逆高さは常に [書き換え制限](default:書き換え制限) だけチェーンの高さより遅れます。
    チェーンの先端付近にあるトランザクションは、まだロールバックされる可能性があります。
    そのブロックがリライトリミットを下回ると、不可逆になります。
