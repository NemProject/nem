# ルートネームスペースを延長する

[ルートネームスペース](default:ルートネームスペース) は、登録 1 回あたりおよそ 1 年という限られた [期間](../../textbook/namespaces.md#duration) のリースを受けます。
初回のリース期間を超えてネームスペースを維持したい場合は、延長する必要があります。

このチュートリアルでは、ルートネームスペースを延長する方法を説明します。

## 前提条件 {: #prerequisites }

* アクティブなルートネームスペースを所有する [アカウント](default:アカウント)。
    [ルートネームスペースを登録する](./register-root-namespace.md) を参照してください。
* トランザクションとリース手数料を支払うための [XEM](default:XEM)。

## 延長するタイミング {: #when-to-extend }

ネームスペースは 2 つの状況で延長できます。

* **リース終了間近:** 更新が許可されるのは、有効期限前の最後の 43200 ブロック（およそ 30 日間）だけです。
    それより前に行った更新の試みはネットワークに拒否されます。

* **猶予期間中:** ネームスペースの期限は切れているものの、期限切れ後 43200 ブロック（およそ 30 日間）続く [猶予期間](../../textbook/namespaces.md#duration) 内にあります。
    この期間に延長すると、ネームスペースはすぐにアクティブ状態へ戻ります。

!!! note "サブネームスペースとモザイクの延長"

    延長が必要なのはルートネームスペースだけです。
    [サブネームスペース](default:サブネームスペース) と関連するすべての [モザイク](default:モザイク) は、ルートネームスペースの有効期間を継承します。

    そのため、ルートネームスペースを延長すると、そのすべてのサブネームスペースとモザイクも自動的に使用可能な状態に保たれます。

## 手順 {: #procedure }

ネームスペースを延長するには、**同じルートネームスペース名** を使って [登録手順](./register-root-namespace.md) を繰り返し、**100 XEM のリース手数料**をもう一度支払います。

トランザクションに署名するアカウントは、ネームスペースの所有者でなければなりません。

プロトコルは、[リース終了間近または猶予期間中](#when-to-extend) の更新だけを受け付けます。

## 期間と制限 {: #duration-and-limits }

各更新では、更新トランザクションを含むブロックの 1 年後までリースが延長されます。前の有効期限から 1 年後ではありません。
そのため、ネームスペースを複数年分前払いすることはできません。

ネームスペースを無期限に維持するには、毎年、更新期間中に更新してください。

詳細については、テキストブックの [期間](../../textbook/namespaces.md#duration) を参照してください。
